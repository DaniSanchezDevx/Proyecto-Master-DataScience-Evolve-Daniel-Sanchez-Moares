# Datos originales

El archivo original `games_march2025_full.csv` no se incluye en el repositorio porque es demasiado pesado para GitHub.

Para reproducir el proyecto:

1. Descargar el dataset **Steam Games dataset 2025** desde Kaggle.
2. Colocar el archivo CSV en esta carpeta con este nombre exacto:

```text
data/raw/games_march2025_full.csv
```

Después se puede ejecutar el proyecto con:

```powershell
.\scripts\run_all.ps1
```
