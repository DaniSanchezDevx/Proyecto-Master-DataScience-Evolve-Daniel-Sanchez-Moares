# Borrador de post para LinkedIn

He terminado un proyecto de análisis de datos sobre videojuegos de Steam usando Python, pandas y Jupyter.

El objetivo era responder a tres preguntas:

- ¿Qué géneros tienen más usuarios estimados por juego?
- ¿Qué géneros tienen mayor tiempo medio de juego?
- ¿Existe relación entre valoraciones positivas, usuarios estimados y tiempo medio?

Una de las partes más importantes del proyecto fue aprender a no quedarme solo con el primer resultado. Al principio, sumar usuarios por género daba cifras enormes y poco realistas, porque un mismo juego puede pertenecer a varios géneros. Por eso decidí usar la media de usuarios estimados por juego como métrica principal.

Algunas conclusiones:

- Los juegos gratuitos consiguen más usuarios estimados medios.
- Los juegos de pago tienen mayor tiempo medio de juego.
- Las valoraciones positivas no tienen una relación fuerte con usuarios o tiempo medio.
- Las reseñas sí están mucho más relacionadas con la popularidad estimada.
